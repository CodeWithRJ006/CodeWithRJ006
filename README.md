### 🚀 What I'm Building (Currently In Progress)
- ⚡ **My Khata:** Fully offline financial trust engine that turns spoken transactions into portable credit certificates. Powered by an on-device Gemma LLM (MediaPipe Inference) and NPU hardware to parse natural speech into a structured local SQLite ledger.
- 🎨 **SwarmCanvas:** Multiplayer WebRTC whiteboard where AI agents compile and deploy UI in real-time.
- 🧠 **ChronosOS:** Graph-based memory architecture (Neo4j + LangGraph) for long-horizon AI agents.
- 🛠️ **AST-Surgeon:** Deterministic AST-based self-healing CI/CD bot using Tree-sitter.

<br/>

### 💎 Featured Deployments & Open Source
- 👁️ **Scene Narrator:** Real-time multimodal vision pipeline processing user-uploaded imagery into descriptive audio narratives via low-latency API integrations (Next.js/Vercel, OpenAI/Gemini).
- 🆔 **Attendrix:** Automated edge-integrated facial recognition pipeline and monitoring dashboard for zero-friction attendance tracking.
- 🏗️ **BuildSphere & Astralab:** Scalable full-stack application scaffolds designed to accelerate backend routing and modular frontend UI generation, featuring cinematic Tokyo Night aesthetics and glassmorphism.
- 🌟 **Open Source Contributor:** GirlScript Summer of Code (GSSoC) 2026.
